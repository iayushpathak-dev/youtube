# Reports

- Weekly: `reports/weekly/YYYY-Www.md` (ISO week). Monthly: `reports/monthly/YYYY-MM.md`. Research phases: `reports/research/YYYY-MM-DD-<phase>.md`.
- Reports summarise and link. Durable findings go into the knowledge files (INDEX.md), not only the report.

## Weekly template
```
# Week YYYY-Www (Mon DD – Sun DD)
## Published (IDs, links)
## Channel numbers (vs last week): Shorts | Long-form (source + pull date)
## What worked / what didn't (FACT → HYPOTHESIS)
## Competitor & market moves this week (links)
## Audience insights (AUD-###)
## Experiments: started / concluded
## Lessons added (LES-###)
## Decisions needed (DEC-### PROPOSED)
## Next week's plan
```

## Monthly template
```
# Month YYYY-MM
## Goals vs results
## Shorts analysis | Long-form analysis (separately)
## Full competitor pass summary (snapshot links)
## Market shifts (ai-landscape entries added)
## Strategy recommendations (→ DEC-### PROPOSED)
## Integrations / access issues
```
