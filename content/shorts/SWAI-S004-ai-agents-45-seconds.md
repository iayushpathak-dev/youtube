## Script (45–60 s, 108 words of narration ≈ 43 s spoken + on-screen pauses)
| Time | Narration | On screen |
|---|---|---|
| 0–3 s | A chatbot answers you. An agent does the work. | Text: "CHATBOT vs AGENT" |
| 3–15 s | Ask a chatbot for cheap flights and you get a list. Ask an agent, and it searches, compares, and books it for you. That's the whole difference: one talks, the other acts. | Simple animation: chat bubble vs a loop of actions |
| 15–40 s | Every agent runs the same loop. Goal. Plan the steps. Use tools like search, email or a spreadsheet. Check the result. Repeat until it's done. That loop is all an agent is. The tools are what make it useful. | Loop diagram: GOAL → PLAN → TOOLS → CHECK ↺ |
| 40–55 s | The catch: agents still make mistakes, so the best ones ask you before anything important. Follow, because I'll build a useful one with you soon, no code needed. | Text: "Human check ✅" |
