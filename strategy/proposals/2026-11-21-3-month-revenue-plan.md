# 3-month plan (Dec 2026 – Feb 2027)

> **Status: PROPOSED (DEC-007), not approved.** Written 2026-11-21 for the earlier developer-only positioning.
> Its cadence ("3 Shorts/week") is superseded by DEC-002 (daily Shorts) and its audience by DEC-001. To be revised after the research phase.

Goal: first income within 90 days, with YouTube as the funnel, not the only source.

## Decisions
- Voice: the creator's own voice (script from Claude, audio recorded on a phone). Claude does visuals and editing.
- Angle: a senior dev builds real apps with AI and reviews what breaks. Titles lead with the tool (Claude Code / Cursor).
- Cadence: 1 long video every Tuesday 7:30 pm IST, plus 3 Shorts (Wed/Fri/Sun) cut from it.

## Revenue (realistic order)
1. **Digital product** (from week 3): the source code + prompt pack of each app built on the channel. Gumroad/Lemon Squeezy, ₹499–999 / $9–19.
2. **Freelance / client builds** (from week 4): "I build your MVP with AI in 2 weeks". The channel is the portfolio. Link in every description.
3. **Affiliate links** (from video 1): hosting/tools used in the videos, only ones that have programs.
4. **Sponsorships**: usually after ~2–5K subscribers. Maybe month 3.
5. **YouTube ads (YPP)**: needs 1,000 subs + 4,000 public watch hours in 12 months (or 1,000 subs + 10M Shorts views in 90 days). Unlikely inside 90 days; check current rules in Studio → Earn.

## Month 1: launch and learn
- W1: Video 1 "I Let Claude Code Build a Real SaaS — Then Reviewed It as a Senior Dev" + 3 Shorts
- W2: Video 2 "Claude Code vs Cursor: Same App, Same Prompt — Which One Ships?"
- W3: Video 3 build video + launch product #1 (code + prompts)
- W4: Full course #1 "Claude Code Full Tutorial: Build & Deploy a Next.js App"
- Weekly: Claude pulls analytics (CTR proxy, retention, traffic sources, search terms) and adjusts the next title/thumbnail/hook.

## Month 2: double down
- Repeat the formats that won in month 1 (by retention and subscribers per video).
- Open the freelance offer. Product #2.

## Month 3: scale
- 2 Shorts/day if Shorts are pulling subscribers. First sponsor outreach if >2K subs.
