## What doesn't
Framework-first titles from small channels: "Cursor AI + Next.js" (277 views),
"Vibe Code ... Next.js + Supabase App" (69), "My Cursor Setup (as a React Developer)" (5.6K).

## Takeaways
1. Lead titles with the **tool** (Claude Code / Cursor), not the framework. React/Next.js go in the
   description and tags, or late in the title.
2. Promise an **outcome**: "build & deploy", "real app", "start to finish", "$X app", "learn 80% in 10 min".
3. Full courses / long beginner tutorials pull the biggest numbers. This fits the monthly 40–60 min course.
4. Most competitors are beginner / no-code. Our angle (a senior dev, real production code, what breaks)
   is under-served. Make it the hook: "what AI got wrong", "senior dev reviews Claude Code's code".
